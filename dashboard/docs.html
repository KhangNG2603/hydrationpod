💡 Tại sao Import trên Web Postman (go.postman.co) báo lỗi?
Trang web Postman chạy trên máy chủ đám mây của Postman ở Mỹ, nên không thể truy cập vào máy tính cục bộ của bạn qua đường link http://localhost:8000.
👉 Cách 1 (Nhanh nhất & Trực tiếp nhất): Sử dụng ngay bảng điều khiển tương tác bên dưới (bấm Gửi Request (Send) để test trực tiếp trên Web).
👉 Cách 2 (Trên Postman Web): Vào Postman ➜ Bấm Import ➜ Chọn tab Raw text ➜ Dán mã cURL bên dưới vào là xong!

⚡ BẢNG COMMAND JSON DEMO NHANH (BẤM VÀO DÒNG ĐỂ NẠP LỆNH)
Kịch bản Request JSON Tác dụng khi Demo
Demo 1: Uống hợp lệ {"command": "SIM_DEMO_SCENARIO_1"} Cộng +150ml đã uống, trừ 150ml trong bình, reset idle_sec = 0, tắt cảnh báo, rung + bíp xác nhận.
Demo 2: Quên uống nước {"command": "SIM_DEMO_SCENARIO_2"} Đẩy idle_sec = 35s, alert_level = 2 → kích hoạt cảnh báo quên uống Cấp 2 (Rung đôi + còi + thông báo Mobile).
Demo 3: Suy tim vượt trần {"command": "SIM_DEMO_SCENARIO_3"} Chuyển HEART_FAILURE (trần 1000ml), đặt đã uống 1050ml → báo động khẩn cấp (còi 2500Hz + rung liên tục + Pop-up đỏ).
MPU6050: Uống hợp lệ {"pitch": 45, "roll": 10, "gyro_dps": 65, "total_acc": 1.05, "duration_ms": 1500, "delta_ml": 150} Mô phỏng cảm biến nghiêng 45° (>35°), giữ 1.5s (≥0.8s) → FSM ghi nhận SENSOR_DRINK (+150ml).
MPU6050: Va chạm / Rơi {"pitch": 20, "roll": 5, "gyro_dps": 180, "total_acc": 2.5, "duration_ms": 400, "delta_ml": 150} Gia tốc 2.5G vượt ngưỡng sốc → FSM vào STATE_IMPACT_REJECTED, bỏ qua nhiễu không tính uống.
Reset dữ liệu ngày {} (POST /api/reset) Đưa lượng đã uống về 0ml, bình về 500ml, tắt toàn bộ cảnh báo.
