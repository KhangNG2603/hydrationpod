💡 Tại sao Import trên Web Postman (go.postman.co) báo lỗi?
Trang web Postman chạy trên máy chủ đám mây của Postman ở Mỹ, nên không thể truy cập vào máy tính cục bộ của bạn qua đường link http://localhost:8000.
👉 Cách 1 (Nhanh nhất & Trực tiếp nhất): Sử dụng ngay bảng điều khiển tương tác bên dưới (bấm Gửi Request (Send) để test trực tiếp trên Web).
👉 Cách 2 (Trên Postman Web): Vào Postman ➜ Bấm Import ➜ Chọn tab Raw text ➜ Dán mã cURL bên dưới vào là xong!
